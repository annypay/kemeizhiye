# 江西柯美纸业项目 · 人员伤亡突发事件应急预案

> 预案类型：生产安全事故 — 人员伤残/死亡类突发事件  
> 适用范围：江西柯美纸业莲花项目全部厂区（含乙方/分包单位施工区域）  
> 牵头部门：总经办  
> 签发部门：总经办  
> 生效日期：2026-08-__  
> 修订记录：V1.0（2026-08 首版，依据 2026-08 碎解车间人员死亡事件处置经验编制）

---

## 一、总则

### 1.1 目的

规范项目范围内发生人员伤残、死亡类突发事件时的应急处置流程，实现四个目标：

1. **生命第一** — 第一时间组织现场急救，最大限度挽救生命；
2. **依法报告** — 严格执行《生产安全事故报告和调查处理条例》等法规的报告义务，杜绝瞒报、迟报、谎报；
3. **信息管控** — 统一口径、防止不实信息扩散至公众平台造成舆情与次生损失；
4. **快速恢复** — 在合法合规前提下尽快恢复施工生产，减少停工损失。

### 1.2 适用范围

- 甲方（柯美纸业）人员、乙方（施工单位）及分包单位人员在厂区内的工伤、意外伤残、突发疾病死亡等事件；
- 无论伤亡人员是否为公司员工，凡发生在项目区域内的事件均适用本预案。

### 1.3 法规依据

| 法规/文件 | 关键要求 |
|-----------|----------|
| 《生产安全事故报告和调查处理条例》（国务院令第 493 号） | 死亡事故：单位负责人接到报告后 **1 小时内**向事故发生地县级以上人民政府安全生产监督管理部门（现应急管理部门）报告 |
| 《中华人民共和国刑法》第一百三十九条之一 | **不报、谎报安全事故罪**：负有报告职责的人员不报或谎报事故情况，贻误事故抢救，情节严重的，处三年以下有期徒刑或拘役；情节特别严重的，处三年以上七年以下有期徒刑 |
| 《工伤保险条例》 | 工伤认定、待遇与赔偿 |
| 《中华人民共和国突发事件应对法》 | 突发事件分级响应与信息发布 |

### 1.4 处置原则

1. **先救人，后论责**：急救优先，责任认定交给事故调查；
2. **先报警报医，后通知内部**：120/110 与法定上报同步启动，内部上报链并行执行；
3. **先依法，后处置**：遗体处置、现场破坏、信息发布均须在警方/监管部门指导下进行；
4. **先控信息，后发通告**：未经总经办授权，任何人不得对外发布事件信息；
5. **人文关怀**：尊重死者与家属，安排专人对接，避免激化矛盾。

## 二、应急组织架构

| 小组 | 牵头 | 职责 |
|------|------|------|
| **总指挥** | 总经理 | 全面决策：是否上报政府、赔偿方案、对外表态 |
| **现场指挥组** | 总经办 + 项目经理 | 现场急救组织、停工/复工指令、警戒线划定、现场保护 |
| **急救联络组** | 当班管理人员 + 保安 | 拨打 120/110、引导救护车/警车路线、AED 取用 |
| **信息管控组** | 总裁办 / 总经办 | 统一口径、拍摄管控、舆情监测、对外/对内通告 |
| **家属对接组** | 行政人资部 + 乙方负责人 | 家属通知、接待、安抚、遗体确认陪同 |
| **善后组** | 行政人资部 + 采购/财务 | 保险报案、工伤认定材料、赔偿协商、配合事故调查 |

> 事件发生后 30 分钟内各组自动进入应急状态，无需等待指令。

## 三、黄金 1 小时处置流程

### 3.1 第 0-5 分钟：现场急救（生命第一）

1. **立即停机**：事发区域设备停机、断电，疏散无关人员，防止二次伤害；
2. **评估伤情**：判断意识、呼吸、脉搏、出血；
3. **拨打 120**：报清厂区位置（莲花县工业园区柯美项目 + 具体车间/区域）、伤情、接应地点；同时**拨打 110** 报备；
4. **现场急救**：
   - 具备急救技能的工友立即实施心肺复苏（CPR）、止血、包扎；
   - 派人去取 AED（如有），按语音提示操作；
   - **不轻易移动伤者**（疑似骨折/脊柱损伤时移动可能致命）；
   - 保持伤者呼吸道畅通，解开领口腰带；
5. **记录**：专人记录事发时间、位置、在场人员、急救措施时间线（精确到分钟）。

### 3.2 第 5-30 分钟：医疗交接与现场管控

1. **引导救护车**：安排人员在厂区大门等候，引导 120 以最快路线到达；
2. **听从医护人员**：
   - 120 到达后现场交由医护人员处置，无关人员后退；
   - 若 120 宣布死亡：**以医护人员宣布为准**，停止一切按压急救；
   - 若亲属/工友情绪激动强行要求继续按压：由医护人员出面解释（"已无生命体征，继续按压无意义"），公司人员**不强行阻拦**，全程录像留证，避免后续纠纷；
3. **现场警戒**：
   - 以事发点为中心拉警戒线（半径 ≥10 米），**警戒区内停工**；
   - 警戒区外其他区域评估后有序恢复作业（减少停工损失）；
   - 未经警方同意，任何人不得移动、触碰现场物品与遗体；
4. **初始影像**：对现场全景、事发位置、周边环境拍照/录像（含时间戳），作为原始状态证据。

### 3.3 第 30-60 分钟：报警、法定上报与内部上报链

**报警（无家属在场/家属已确认后均可）**：

1. **110 报警**：如实说明"我单位施工现场发生人员死亡事件"，请求公安到场；
2. 公安到场后：配合法医、民警、刑警、特警现场勘验（排除他杀/自杀），由**警方决定遗体处置方式**（通知殡仪馆运走）；
3. **关键红线**：企业**不得自行联系殡仪馆运走遗体**——遗体处置权在公安机关/医疗机构，自行处置涉嫌破坏现场、掩盖事故，且违反法规。

**法定上报（死亡事故必须执行）**：

| 顺序 | 对象 | 时限 | 方式 |
|------|------|------|------|
| 1 | 属地应急管理局（莲花县应急管理局） | **1 小时内**（自单位负责人获悉起算） | 电话 + 书面快报 |
| 2 | 属地派出所/公安局 | 立即 | 110 |
| 3 | 园区管委会（如属园区管辖） | 2 小时内 | 电话 |
| 4 | 住建局（涉及建筑施工的） | 24 小时内 | 电话/书面 |

**内部上报链（并行）**：

```
现场第一发现人 → 当班管理人员 → 项目经理 → 总裁办 / 总经办 → 总经理（贾少军） → 董事长
        ↓
    保安/门岗（配合警戒与信息管控）
```

**如实上报三要素**：时间、地点、经过如实；伤亡人数如实；**不隐瞒、不夸大、不缩小**。

### 3.4 信息管控纪律（全流程执行）

1. **统一口径**：对外口径由总经办拟定，只表述"发生一起人员伤亡事件，正在依法处置，具体以官方通报为准"；
2. **拍摄禁令**：现场所有人员（含乙方）禁止拍摄遗体、血腥画面；管理人员逐一口头告知并登记；
3. **网络禁令**：禁止将现场照片、视频发布至微信朋友圈、抖音、快手、微博等任何公众平台；
4. **舆情监测**：信息管控组安排专人监测本地自媒体/短视频平台，发现传播立即联系平台删除 + 内部溯源；
5. **对外发言**：除总经理/总经办指定发言人外，任何人不得接受媒体采访、不得向无关人员透露细节。

## 四、家属应对（双分支）

### 4.1 分支 A：现场无家属在场

1. **依法处置**：遗体由警方/医疗机构依法处置，企业不自行联系殡仪馆；现场按 3.2/3.3 执行；
2. **通知家属**：通过乙方劳务负责人获取家属联系方式，由家属对接组**温和、如实**通知（不透露未经确认的细节，建议"突发疾病/意外，正在抢救/已送医，请尽快赶来"分步告知，给家属心理缓冲）；
3. **接站与安置**：家属抵达后安排专人接站、食宿，全程陪同；
4. **遗体告别**：在殡仪馆安排告别环节，尊重家属习俗。

### 4.2 分支 B：现场有众多亲属（本次实际情形，标准化）

1. **稳控情绪**：由乙方负责人出面安抚亲属，家属对接组协助，避免家属与急救人员冲突；
2. **接受现实确认**：配合家属进行遗体确认（拍照/指认），满足合理要求（如再确认一次）——**以医护人员意见为准**处理"强行要求无效按压"：由 120 人员解释，公司不强行阻拦、全程录像；
3. **报警时机**：家属确认完成后**立即报警**（本次实践：家属确认 → 报警 → 法医/民警/特警/刑警到场排除他杀自杀 → 警方通知殡仪馆运走遗体——此路径已固化为标准流程）；
4. **谈判与赔偿**：
   - 通知乙方立即启动保险（工伤保险/雇主责任险）；
   - 死亡赔偿协商由善后组牵头，**乙方承担主体责任**，甲方全程参与监督；
   - 涉及重大金额时上报总经理决策；
5. **人文关怀**：全程保持克制与尊重，任何情况下不与家属发生肢体冲突；家属有过激行为时报警处理。

## 五、事故调查配合

1. **资料保全**（24 小时内封存备查）：
   - 事发区域监控录像（立即拷贝，防止覆盖）；
   - 人员名册、劳动合同/劳务协议、三级安全教育记录、体检记录；
   - 施工方案、作业票、设备检修记录；
2. **询问配合**：配合应急管理局/公安/住建局调查询问，如实陈述；
3. **第三方鉴定**：配合尸检、设备检测等鉴定工作；
4. **调查报告**：调查结束后形成内部报告，明确整改措施并落实闭环。

## 六、善后与恢复

1. **保险报案**：24 小时内完成工伤/雇主责任险报案；
2. **赔偿落实**：依法依规协商赔偿，签订赔偿协议（注明一次性了结条款）；
3. **复工评估**：排除现场隐患、取得监管同意后，分区域恢复施工；
4. **心理疏导**：对目击工友（尤其实施急救者）安排心理疏导；
5. **复盘整改**：事故结案后召开复盘会，更新本预案及作业安全规程，向全员通报。

## 七、附则

1. 本预案与《保安日常工作规范》衔接：事发时保安执行警戒、车辆引导、信息管控配合；

3. 乙方单位须在本预案框架下制定其内部响应细则，并纳入合同安全条款。

## 附录 C：案例复盘（内部教训素材 · 匿名化）

> **事件代号**：2026-08 碎解车间事件（已匿名化，仅存事件过程与教训，不涉及个人身份信息）

| 环节 | 实际情况 | 固化进预案 |
|------|----------|------------|
| 急救 | 工友按压急救未果，120 到达宣布死亡 | 3.1 急救流程 + AED 配置 |
| 亲属干预 | 众多工友为亲属，强行要求 120 无效按压 | 4.2 亲属应对 + 医护人员出面解释、全程录像 |
| 家属确认 | 家属自宜春赶到现场确认遗体 | 4.2 分支 B 标准化 |
| 报警 | 确认后报警，法医/民警/特警/刑警到场排除他杀自杀 | 3.3 报警流程 |
| 遗体处置 | 警方通知殡仪馆运走 | 3.3 关键红线：企业不得自行联系殡仪馆 |
| 信息管控 | 现场信息管控 | 3.4 信息管控纪律 |

**本次事件三大教训**：

1. **报告时效是法律红线**：死亡事故必须 1 小时内报应急管理部门，任何时候不得以"先处理现场"为由拖延上报；
2. **遗体处置必须依法**：企业绝不能自行联系殡仪馆运走遗体，必须由警方/医疗机构处置——企业想做的是"快速恢复施工"，正确做法是警戒分区 + 其他区域有序复工，而非移动遗体；
3. **信息管控与人文关怀并重**：既防止不实信息扩散，又须尊重家属与死者，避免激化矛盾引发二次冲突。
