## 二、文档生命周期工作流

```
起草（00-临时存放） → 你确认（【待归档】） → Agent 入库 → 提交推送
        │                    │                      │
   状态标记：              改口说"入库"        1. 按内容归入 01~09
   【待编辑】【待确认】                         2. 正式命名（见第五节）
   【待归档】                                   3. 你手改了 Office 版 → 以终稿为准回写 md
                                               4. 运行 gen_index.js 更新 INDEX.md
                                               5. git commit + push
```

**三条铁律**：① 临时区文件不自动提交 git；② 归档以你的终稿为准（Office 改了回写 md，没改用 md 生成 Office 版）；③ 超过 30 天未归档的文件由 Agent 提醒处置。

## 五、命名规范（强制规则）

### 5.1 文件命名

```
[日期YYYYMMDD]-[主体]-[事项]-[版本].[扩展名]
```

| 要素 | 规则 | 示例 |
|------|------|------|
| 日期 | 一律 `YYYYMMDD` 前缀，无空格 | `260815-柯美纸业-电站钢结构补充协议-百世德.pdf` |
| 主体 | 甲方-乙方 或 专业-负责人 | `4600纸机_周汇报_0810.xlsx` |
| 版本 | `v1/v2/v3` 紧贴扩展名前；最新版不写版本号 | `公司信息汇总.xlsx`（当前版） |
| 状态 | 仅限临时区使用 | `【待编辑】【待确认】【待归档】` |

**禁止**：文件名带 `(1)(2)(3)` 下载后缀、`~$`、`.bak`、空格分隔日期。违规由 `check_repo.js` 检出。

### 5.2 目录命名

| 类型 | 格式 | 示例 |
|------|------|------|
| 月度归档 | `YYYY.MM/` | `01-进度计划/月度计划表/2026.08/` |
| 会议日期归档 | `YYYYMMDD/` | `03-例会汇报/…/各专业汇报内容/20260819/` |
| 录音归档 | `YYYY-MM-DD/` | `会议录音/2026-08-12/` |
| 模板/归档区 | `_` 前缀 | `_模板-…`、`_archive/` |

### 5.3 版本策略

- 同一文档保留 1 个**当前版**（不带版本号）+ 历史版移入 `_archive/`；
- 当前权威版判定：汇总类看"数据截止"字段，制度类看 README/INDEX 标注。

## 六、核心工作流

### 6.1 重大节点进度追踪闭环（7 步法）

> 流程文档：`04-进度督察/通报与处罚存档/重大节点进度督察工作流程.html`

收计划 → 理节点 → 日对照 → 双确认 → 出通报（JK 编号）→ 登记存档 → 闭环复查

### 6.2 三级追责标准

| 级别 | 触发 | 措施 | 签批 |
|------|------|------|------|
| 🟡 通报 | 当月首次未完成 | 公开通报，限当日内提交整改计划 | 经办人+责任人 |
| 🟠 警告 | 通报后再次未完成 | 计入月度考核，联动处罚存档，抄送行政部+采购部 | +总监确认 |
| 🔴 罚款 | 第三次未完成或重大影响 | 扣减金额/外协按合同罚没，上报公司领导 | +总经理批准 |

### 6.3 周例会汇报链

各专业负责人 → 月度计划表 → 总经办汇总 → 董事长例会 PPT + 汇报数据 → 工作总结与计划

## 八、维护指南（Agent 操作手册）

### 8.1 日常入库（你确认后执行）

1. 从 `00-临时存放/` 取【待归档】文件，按第一节归入对应目录；
2. 按第五节正式命名；手改 Office 版则回写 md 源头；
3. `node scripts/gen_index.js` 更新 INDEX.md；
4. `git add -A && git commit` + push。

### 8.2 卫生检查

```bash
node scripts/check_repo.js   # 输出违规清单：重复后缀/临时文件/bak/嵌套/大文件/散文件
node scripts/gen_index.js    # 重新生成 INDEX.md
```

### 8.3 各专项流程

| 事项 | 操作 |
|------|------|
| 新增月度计划 | `01-进度计划/月度计划表/YYYY.MM/`，土建专项放 `土建/` 子目录 |
| 新增周汇报 | `03-例会汇报/董事长例会/各专业汇报内容/YYYYMMDD/` |
| 新增合同 | `02-合同/` 对应分箱，命名 `YYYYMMDD-甲方-乙方-事项.pdf` |
