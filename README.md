## 一、项目背景

江西柯美纸业有限公司在萍乡市莲花县建设造纸生产基地，当前处于大规模土建+安装并行阶段。总经办作为项目管理中枢，承担以下核心职能：

| 职能 | 说明 |
|------|------|
| **进度督察** | 每日对照施工计划，追踪重大节点完成情况，未完成则逐级通报/警告/罚款 |
| **周例会运转** | 每周汇总各专业进展、倒排工期、协调资源 |
| **政府沟通** | 与地方政府部门衔接审批、用地、环保等事项 |
| **采购跟踪** | 跟踪各专业设备/材料采购进度，预警延期风险 |
| **合同管理** | 土建施工、钢结构、设备采购等合同归档 |
| **人事行政** | 通报批评、调查报告、重要工作推进单 |
| **行业调研** | 同行/供应商/客户单位信息收集 |

**关键工期节点**（截至 2026-07 周例会数据）：

| 系统 | 目标 | 倒计时（截至 7.7） |
|------|------|---------------------|
| 水处理 | 通水运行 | ~83 天 |
| 电站 | 供电 | ~83 天 |
| 5600 车间 | 试运行 | ~111 天 |
| 厂区供电 | — | ~83 天 |
| 厂区供水 | — | ~83 天 |
| 4600 纸机 | 试运行 | 2026-12-18，~163 天 |

## 六、核心工作流

### 6.1 重大节点进度追踪闭环（7 步法）

> 详见 `重大节点进度追踪通报及存档/重大节点进度督察工作流程.html`

```
收计划 → 理节点 → 日对照 → 双确认 → 出通报 → 登记存档 → 闭环复查
  │        │        │        │         │         │          │
  ▼        ▼        ▼        ▼         ▼         ▼          ▼
土建单位  提取完成  每日对照  施工方    未完成即  警告/罚款   整改到期
上传巷道  节点生成  当天到期  回执+     填制通报  级联动登记  复查对比
图施工计划 汇总表   事项截图  项目部    JK编号   处罚存档    更新汇总表
(原件归档) (日期升序)        现场核查  (拍照发群) (抄送行政部 (纳入下次
                                         +采购部)  重点跟踪)
```

### 6.2 三级追责标准

| 级别 | 触发条件 | 措施 | 签批要求 |
|------|----------|------|----------|
| 🟡 **通报** | 当月首次未完成 | 公开通报，限当日内提交整改计划 | 经办人 + 责任人签字 |
| 🟠 **警告** | 通报后再次未完成 | 计入月度考核，联动处罚存档，抄送行政部+采购部 | + 总监确认 |
| 🔴 **罚款** | 第三次未完成或重大影响 | 扣减金额 / 外协按合同罚没工程款，上报公司领导 | + 总经理批准 |

### 6.3 周例会汇报链

```
各专业负责人 → 填写月度计划表（模板v2） → 段伟汇总
                                            ↓
           董事长例会 PPT ← 总经办周例会汇报内容（漆江峘） ← 各专业周报
                                            ↓
                           总经办本周工作总结与下周工作计划
```

### 6.4 文档联动关系

```
重大节点进度追踪通报（JK-2026-xxxx）
    │  含警告/罚款时联动登记
    ▼
重大节点进度追踪处罚存档（累计台账）
    │  抄送
    ├── 行政部
    └── 采购部
```

### 8.2 新增合同

1. PDF 文件放入 `土建相关合同/` 对应子目录
2. 命名格式：`[日期YYMMDD]-[甲方]-[乙方]-[事项].pdf`
3. 金额超过 100 万的在文件名中标注金额
4. 在 README 对应表格中追加条目

### 8.3 新增通报

1. 基于 `重大节点进度追踪通报v2.docx` 模板填制
2. 分配唯一编号 `JK-2026-xxxx`（在现有最大流水号上 +1）
3. 放入 `重大节点进度追踪通报及存档/各专业通报/`
4. 若为警告/罚款级，同步更新 `重大节点进度追踪处罚存档v2.docx`
5. 更新 README 中编号流水记录

### 8.4 新增外部企业信息

1. 在 `单位情况/` 下新增 `.xlsx` 文件
2. 按 `公司信息汇总v3.xlsx` 的字段标准填写
3. 同步更新汇总表版本号（v3 → v4）

### 8.5 新增各专业周例会汇报

1. 各专业负责人每周提交 `.xlsx` 汇报文件
2. 放入 `董事长例会/各专业汇报内容/[年份].[月份]/`
3. 命名格式：`[专业]_[类型]_[日期MMDD].xlsx`（如 `制浆_周汇报_0810.xlsx`）
4. 总经办汇总后生成 PPT 放入 `例会PPT/`
5. 更新 README 对应月份文件列表

### 8.6 新增会议录音

1. 董事长例会现场录音（`.m4a`）按会议日期归档
2. 目录格式：`董事长例会/会议录音/[YYYY-MM-DD]/`
3. 命名格式：`[发言人]_[日期YYYYMMDD].m4a`（如 `总经理_20260812.m4a`）
4. 更新 README 对应日期目录列表
5. ⚠️ 录音文件体积较大（单个约 10MB），注意仓库体积，必要时考虑 Git LFS
