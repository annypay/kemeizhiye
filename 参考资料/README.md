## 维护规则

1. 本目录仅存放相对稳定的参考资料，不参与项目日常文件、周例会材料或临时拟稿的流转。
2. 新增资料按主题建立子目录；需要统一浏览时，可在对应资料集内增加 HTML 汇总页。
3. 替换原始资料时保留最新权威版本；旧版移入 `_archive/` 或在资料集内标注版本与日期。
4. 文件增删后运行 `node scripts/gen_index.js` 更新全库索引；目录结构调整时同步更新本文件与根目录 `README.md`。
