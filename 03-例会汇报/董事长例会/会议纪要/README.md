# 会议纪要 — 编制规范与流程

> 本目录存放董事长周例会会议纪要。由总经办签发。

---

## 一、编制流程（每期周例会）

```
① 各专业提交周汇报        → 03-例会汇报/董事长例会/各专业汇报内容/YYYYMMDD-YYYYMMDD/
② 总经办汇总汇报          → 同目录《总经办周例会汇报内容X.XX.xlsx》
③ 纪要员转录补充          → 由总经办将会议内容转录写入纪要底稿 docx
                             （当前环节：漆江峘自行转录补充）
④ Agent 整理草案          → 深度阅读②的目标周计划列 + ③转录稿 + 未关闭事项，整理三版纪要和待确认事项增量
⑤ 总经办确认签发          → 你过目定稿 → 签发：总经办
⑥ 台账更新与归档          → 确认事项登记/更新工作台账 → 更新 INDEX.md → git commit + push
```

**分工原则**：转录（听会记录）由人完成，整理（结构化、格式、风格统一）由 Agent 完成。

草案先放 `00-临时存放/`，且不自动提交。新增事项只有在纪要经确认后才登记到 `04-进度督察/工作台账/工作事项总台账.md`；既有事项只有完成复查并附证据后才可关闭。

## 二、每期产出（三版六件）

| 文件 | 用途 | 特点 |
|------|------|------|
| `YYYYMMDD-YYYYMMDD-董事长例会纪要-总经理版` | 呈总经理 | **极简**：只体现关键时间节点 + 本周决策 + 指示要点 |
| `YYYYMMDD-YYYYMMDD-董事长例会纪要-董事长版` | 呈董事长/存档 | 完整：会议信息 + 时间节点 + 决策 + 指示 + 跟踪事项 |
| `YYYYMMDD-YYYYMMDD-董事长例会纪要-完整版（群发）` | 发公司群 | 精炼一页：董事长讲话核心 + 总经理讲话核心 + 重点时间节点 + 本周决策 |
| 每份均含 `.md`（源头版）+ `.docx`（打印发放版） | — | md 供 git diff 与程序化处理，docx 供打印 |

另输出 `YYYYMMDD-YYYYMMDD-董事长例会-待确认事项【待确认】.md`，列出候选事项、来源段落、责任、期限和缺失信息；它不是正式台账。

> **一致性要求**：三版内容同源——董事长/总经理讲话核心在 md 中各自成段，任何一版修改（尤其用户手改 docx）须同步回写对应 md 源头，三版之间同步修订，避免版本漂移。

**统一风格**：抬头「江西柯美纸业有限公司」；标题黑体居中；正文仿宋/微软雅黑；表格表头蓝底；落款「签发：江西柯美纸业有限公司 总经办」右对齐 + 日期。纪要编号：`JK-HY-YYYYMMDD`。

## 三、命名规则（周前缀体系）

**未来周计划类文档目录统一用 `YYYYMMDD-YYYYMMDD` 命名**，如当周为 2026-08-24 至 2026-08-30：

```
20260824-20260830
        └─周一 ───┘ └─周日 ───┘
```

| 文档 | 命名 | 示例 |
|------|------|------|
| 各专业汇报目录 | `YYYYMMDD-YYYYMMDD` | `各专业汇报内容/20260824-20260830/` |
| 会议纪要目录及文件 | `YYYYMMDD-YYYYMMDD/` 与同前缀文件名 | `会议纪要/20260824-20260830/20260824-20260830-董事长例会纪要-董事长版.docx` |
| 周例会名单 | `周例会名单+MMDD` | `周例会名单08240830.xlsx` |
| 例会 PPT | `各部门周例会工作汇报内容PPT+MMDD` | `…PPT825.pptx` |

历史周目录和文件前缀（如 `2026824830`、`20260824830`）保留不改。对已有历史周使用其现有前缀检索和关联；仅新建周期使用新格式。

**检索关联**：同一周的纪要、总经办汇报、各专业汇报、总监文档共享周区间或工作事项编号；用周区间或 `JK-RW-YYYY-NNNN` 可关联当周全部材料。

## 四、文档联动

```
各专业汇报内容/20260824-20260830/…（各专业 xlsx）
        │ 汇总
        ▼
总经办周例会汇报内容8.25.xlsx（【重点工作计划（8.25~.8.30）】列）
        │ 转录+整理 + 未关闭事项复盘
        ▼
会议纪要/20260824-20260830/三版纪要 + 待确认事项增量
        │ 经总经办确认
        ▼
工作事项总台账.md（新增 / 状态更新 / 复查安排）
        │ 支撑
        ├── 例会PPT/各部门周例会工作汇报内容PPT825.pptx
        └── 周例会名单/周例会名单08240830.xlsx
```

## 五、归档与版本

- 当期纪要与当期汇报目录同生命周期；过月后由总经办确认再整体移入 `_archive/`；
- 转录底稿（如 `20260825会议纪要.docx`）在正式纪要签发后移入 `_archive/`；
- 旧版纪要修改以 `v2` 后缀迭代，最新版不带版本号。

纪要文件、PPT 或 Office 终稿入库不等于事项完成。每一项执行结论应关联 `JK-RW` 编号；状态和关闭证据只在工作事项总台账维护。
