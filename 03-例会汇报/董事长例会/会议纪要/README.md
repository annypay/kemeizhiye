# 会议纪要 — 编制规范与流程

> 本目录存放董事长周例会会议纪要。由总经办签发。

---

## 一、编制流程（每期周例会）

```
① 各专业提交周汇报        → 03-例会汇报/董事长例会/各专业汇报内容/2026+当周起始/
② 总经办汇总汇报          → 同目录《总经办周例会汇报内容X.XX.xlsx》
③ 纪要员转录补充          → 由总经办将会议内容转录写入纪要底稿 docx
                             （当前环节：漆江峘自行转录补充）
④ Agent 整理成纪          → 深度阅读②的目标周计划列 + ③转录稿，整理两份纪要
⑤ 总经办确认签发         → 你过目定稿 → 签发：总经办
⑥ 归档提交               → 更新 INDEX.md → git commit + push
```

**分工原则**：转录（听会记录）由人完成，整理（结构化、格式、风格统一）由 Agent 完成。

## 二、每期产出（四件套）

| 文件 | 用途 | 特点 |
|------|------|------|
| `2026YYYYMMDD-董事长例会纪要-总经理版` | 呈总经理 | **极简**：只体现关键时间节点 + 本周决策 + 指示要点 |
| `2026YYYYMMDD-董事长例会纪要-董事长版` | 呈董事长/存档 | 完整：会议信息 + 时间节点 + 决策 + 指示 + 跟踪事项 |
| 每份均含 `.md`（源头版）+ `.docx`（打印发放版） | — | md 供 git diff 与程序化处理，docx 供打印 |

**统一风格**：抬头「江西柯美纸业有限公司」；标题黑体居中；正文仿宋/微软雅黑；表格表头蓝底；落款「签发：江西柯美纸业有限公司 总经办」右对齐 + 日期。纪要编号：`JK-HY-YYYYMMDD`。

## 三、命名规则（周前缀体系）

**周计划类文档目录统一用 `2026 + 当周起始` 命名**，如当周为 8.24—8.30 周：

```
2026824830
 └─ 2026 │ 824 │ 830
         └─当周起始 8.24 ─┘当周结束 8.30
```

| 文档 | 命名 | 示例 |
|------|------|------|
| 各专业汇报目录 | `2026+当周起始`（8位） | `各专业汇报内容/2026824830/` |
| 会议纪要 | `2026+当周起始-董事长例会纪要-XX版` | `2026824830-董事长例会纪要-董事长版.docx` |
| 周例会名单 | `周例会名单+MMDD` | `周例会名单08240830.xlsx` |
| 例会 PPT | `各部门周例会工作汇报内容PPT+MMDD` | `…PPT825.pptx` |

**检索关联**：同一周的纪要、总经办汇报、各专业汇报、总监文档共享 `2026824830` 前缀，全库检索该前缀即可一键关联当周全部文档。

## 四、文档联动

```
各专业汇报内容/2026824830/…（各专业 xlsx）
        │ 汇总
        ▼
总经办周例会汇报内容8.25.xlsx（【重点工作计划（8.25~.8.30）】列）
        │ 转录+整理
        ▼
会议纪要/2026824830-董事长例会纪要-董事长版 / 总经理版
        │ 支撑
        ├── 例会PPT/各部门周例会工作汇报内容PPT825.pptx
        └── 周例会名单/周例会名单08240830.xlsx
```

## 五、归档与版本

- 当期纪要与当期汇报目录同生命周期；过月后整体移入 `_archive/`；
- 转录底稿（如 `20260825会议纪要.docx`）在正式纪要签发后移入 `_archive/`；
- 旧版纪要修改以 `v2` 后缀迭代，最新版不带版本号。
