## 一、项目概况

| 项目信息 | 内容 |
| --- | --- |
| **项目名称** | 山东太阳宏河纸业有限公司年产45万吨天然纤维素及配套工程技改提升项目 |
| **建设单位** | 山东太阳宏河纸业有限公司 |
| **建设地点** | 山东省邹城市太平镇（邹城市工业园区） |
| **项目性质** | 技改（在年产35万吨天然纤维素循环经济一体化项目基础上进行技改） |
| **总占地面积** | 511,500平方米（约767.25亩） |
| **新增用地面积** | 234,000平方米（约351亩，用于建设木片堆场） |
| **建（构）筑物占地面积** | 411,253.35平方米 |
| **建筑面积** | 73,950.35平方米 |
| **主要原料** | 木片 |
| **产品** | 天然纤维素（溶解浆） |
| **主要工艺流程** | 木片筛选 → 水解 → 蒸解 → 洗涤 → 稀释 → 漂白 → 除杂 → 压榨 → 干燥 → 包装 |
| **设备情况** | 更新除节机、压力筛、喂料泵、低浓磨、渣浆磨等设备307台（套），利用原有再碎机、木片泵、输送泵、中浓泵、洗浆泵等设备1067台（套），改造后设备总计1374台（套） |
| **配套工程** | 对废液焚烧炉及污水处理系统等进行升级改造 |
